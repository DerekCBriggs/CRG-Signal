# CRG-Signal: Claim B growth prototype for Project Signal

A working draft from CADRE at the University of Colorado Boulder. It shows how
content-referenced growth reporting could work for Project Signal's Claim B,
Quantitative Analysis and Modeling.

View it at https://derekcbriggs.github.io/CRG-Signal/

## What it shows

| View | Contents |
| --- | --- |
| Class | Grade 5 Claim B scores for a class against five learning progression levels, with a comparison to Grade 3 or Grade 4 Smarter Balanced scores and groups with instructional next steps |
| Student | One student's scores in Grades 3, 4, and 5, a plain-language statement, notes on measurement error, and chances of success on exemplars |
| Task | The steps of Signal's worked example, "Water in Our Schoolyard," placed by task phase and Claim B level |
| Learning progression | The five levels and indicators for targets B1 to B4 |
| How levels are set | Hypothetical item locations by level, with a draggable student score |

A guided tour ("Take the tour") walks through the main ideas.

## Status

This is a working draft for Smarter Balanced and Project Signal. Students,
scores, and item locations are hypothetical. The level descriptions are a draft
for revision. The link between Project Signal and the Smarter Balanced scale is
assumed and subject to change. Task pages come from the Project Signal worked
example (Appendix B) and are marked as a prototype.

## Running it

The site is static: HTML, CSS, JavaScript, and one data file. Open `index.html`
in a browser, or serve the folder with any static web server.
